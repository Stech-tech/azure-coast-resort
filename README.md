# 📌 Azure Coast – Full Stack Contact System

A simple full-stack web application that allows users to send messages through a contact form. All messages are stored in a database and can be managed through an admin dashboard.

---

## 🚀 Features

- Contact form for users to send messages  
- Stores messages in a backend database  
- Admin dashboard to view all messages  
- Delete messages from admin panel  
- Real-time data fetching from backend API  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  
- Node.js  
- Express.js  
- SQLite

## 📂 Project Structure

- Frontend: HTML, CSS, JavaScript files  
- Backend: Node.js + Express server  
- Database: SQLite local file database  

---

## ⚙️ How to Run Locally

1. Install Node.js  
2. Run `npm install`  
3. Start server using `node server.js`  
4. Open `contact.html` in browser  
5. Use the form to send messages
